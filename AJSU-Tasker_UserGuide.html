1. Overview

AJSU-Tasker is a biweekly work log that runs in your browser as a single HTML file. It replaces the manual Excel-based work log for EPC employees. The application handles memo formatting, tracks your activity across pay periods, and builds productivity trend charts automatically over the course of the year.

Your data stays on your computer. Nothing is sent to a server or shared with any external service.

The application covers the full 26-period EPC pay calendar for 2026.

2. How to Use the Application

The navigation bar at the top contains all tabs. Work flows left to right across a pay period:

  • Guide - Quick reference inside the application.
  • Planning - Set your objectives, to-do list, deadlines, and notes before the period starts. Feedback from your supervisor also goes here and carries to the memo.
  • Week 1 and Week 2 - Log your daily activity blocks here. Each day shows Monday through Friday with five rows. Add more rows with the + Add Row button if needed.
  • Employee View - Your personal metrics for the current period: completion rate, category breakdown, priority distribution, and worksite distribution.
  • Management View - Items requiring your supervisor's attention, high-priority completions, and a full count of every status for the period.
  • Dashboard - Visual charts for the current period's status, category, and worksite distributions.
  • Trends - Cross-period charts that build automatically as you work through the year. No action required from you.
  • Blocks - Every activity you have logged, across every pay period, in one scannable list sorted by date. Use it to confirm at a glance that your work is all still there. It is read-only: edit blocks in Week 1 and Week 2, not here.
  • Memo - The Tasker Memo. Fill in your name, department, and supervisor, then print or save as PDF.

The Export Toolbar

Below the tab bar is a second row holding the backup and export buttons - Restore Backup, Download Backup, Export CSV, and Print Memo. These are kept on their own row so they cannot be clicked by accident while you are switching tabs or pay periods.

Status Color Coding

Status dropdowns change background color to reflect the current value, so you can scan the week at a glance:

3. Getting Started

What You Need

  • A Windows computer with Chrome or Edge (recommended) or Firefox.
  • The file: AJSU-Tasker-v6.html saved to your computer. Your desktop or a dedicated folder both work well.
  • An internet connection the first time you open the file so the charting library can download and cache. After that, the application works without internet.

Opening the Application

Double-click the HTML file. It opens in your default browser. No installation, no setup required. Your last saved data loads automatically every time you open it.

Security Notice on First Open Windows may show a SmartScreen or "unrecognized file" warning when you first open a downloaded HTML file. This is standard Windows behavior for files downloaded from the internet. To dismiss it permanently: right-click the file, select Properties, check the Unblock box, and click Apply. You will not see the warning again for that file. AJSU-Tasker is published by AJSU | FUTURE STRATEGY.

Automatic Downloads Setting

When you click Download Backup, your browser saves a file to your computer. Some browser settings block this automatically. If backup files do not save when you click the button:

  • Chrome or Edge: Go to Settings, then Privacy and Security, then Site Settings, then Automatic Downloads. Add the folder where your HTML file is saved to the Allowed list.
  • Firefox: Go to Settings, then General, then Files and Applications. Make sure the download folder is set and automatic saving is allowed.

Selecting Your Pay Period

Select your current pay period from the dropdown at the top right. Each option shows the work date range followed by the pay date in parentheses. The dates for Week 1 and Week 2 update automatically. Your previously entered data for that period loads immediately.

Starting a New Year

To start fresh for a new year without losing your current year's data, save a copy of the HTML file to a new folder. In Chrome and Edge, each unique file location has its own independent storage. The new copy opens with no existing data.

4. Daily Workflow

Log your blocks at the end of each workday or the start of the following day while the work is fresh. Logging everything at the end of a pay period is possible but takes longer.

  1. Confirm the correct pay period is selected in the top-right dropdown.
  2. Click Week 1 or Week 2 for the week you are logging.
  3. Find the day row for today (labeled Monday through Friday with the calendar date).
  4. For each block of work: select a Category, type the Activity, set Status and Priority, select a Worksite, and add any Notes.
  5. The application saves as you type. No Save button is needed.
  6. At the end of your session, click Download Backup to save a permanent file copy to your computer.
Need more rows? Click the + Add Row button in any day header. You can add as many rows as needed. They save automatically like the default rows.

7. Your Metrics

Employee View

Answers the question: How is this period going for me?

  • Completion Rate - Percentage of your logged blocks marked Complete. Green above 75%, red below 25%. A low rate is not necessarily a problem if many blocks are still in progress.
  • Blocks by Category - How your effort is distributed across the five categories.
  • Priority Distribution - How many blocks are Standard, Elevated, or High priority.
  • Blocks by Worksite - Where your work was performed this period. Only shows if worksite data has been entered.

Management View

Answers the question: What needs attention and what got done?

  • Items Requiring Attention - Count of blocks with On Hold, Follow-up, Delegated, or Re-assigned status. Turns red when greater than zero.
  • High Priority Items Complete - Count of Elevated or High priority blocks marked Complete.
  • Period Status Summary - Full count of all seven statuses. Quick reference for the overall shape of the period.
  • Items Requiring Review - Detailed list of each escalated block with the day and any notes.

Dashboard

Visual charts of the current period's status distribution, category distribution, and worksite distribution. Use these for a quick visual read or to present in a team meeting.

8. Trends Over Time

The Trends tab shows how your metrics change across pay periods throughout the year.

How It Works

Trend data is recorded automatically. Each time you switch pay periods, the application saves a compact summary of the period you are leaving. No downloads, no extra steps. Before any data is recorded, the Trends tab shows a dimmed preview of the metrics it will track. After working in two or more pay periods, the charts populate with your actual data.

ChartWhat It Shows
Completion Rate Over TimeYour completion percentage period by period, with a direction indicator (Improving, Stable, or Declining) based on recent vs. earlier periods.
Items Requiring AttentionCount of escalated blocks per period. Helps identify whether issues are increasing or decreasing over time.
Category Mix by PeriodHow the type of work you do shifts from period to period.
Priority Distribution by PeriodWhether Standard, Elevated, and High priority blocks are shifting over time.
Worksite Distribution by PeriodWhere your work was performed, period by period. Only appears if worksite data has been recorded.
Trend data is in every backup file Each backup JSON file contains the full history of period summaries. Restoring a backup also restores all historical trend data from that file.

9. The Tasker Memo

The Memo tab generates your Tasker Memo automatically from your Week 1 and Week 2 entries.

Filling In the Header

The memo header has two columns. All fields are editable by clicking directly on them.

  • Column 1: Prepared On (auto-fills with today's date), Name, Department
  • Column 2: Pay Period (auto-fills from your period selection), Supervisor

Name, Department, and Supervisor fields are blank by default so each user fills in their own information. Once filled in, these values are saved and restored on every session.

The Pay Period field shows the work date range for the selected period. You can click on it to make small adjustments before printing if needed. It resets to the computed value whenever you switch pay periods.

Supervisor Notes

The Supervisor Notes section below the header pulls from the Feedback field in the Planning tab. Edit it there for persistent changes. Any edits made directly on the Memo tab are for the current preview only.

Activity Tracker

The Activity Tracker table lists all activities from Week 1 and Week 2, grouped by week. Each entry shows the date, activity, status, and notes. It populates automatically. You do not need to do anything to fill it in.

Worksite and Category are not included in the Activity Tracker. Worksite is a personal metric. Category is an internal classification. The Tasker Memo communicates outcomes to management, not internal labels.

Signature Lines

The Employee Signature and Supervisor Signature lines appear at the bottom of the memo for manual signing after printing.

10. Printing and PDF Export

Printing the Memo

  1. Make sure all blocks for the period are entered in Week 1 and Week 2.
  2. Check that the Feedback field in the Planning tab is current. It syncs automatically to the memo.
  3. Click the Memo tab or the Print Memo button to review the Tasker Memo layout.
  4. Fill in your name, department, and supervisor if not already set.
  5. Click Print Memo at the top right.

Saving as PDF

In the browser print dialog, set the destination to Save as PDF. This produces the cleanest output and respects the memo's margin settings.

Avoid "Microsoft Print to PDF" The Windows "Microsoft Print to PDF" printer option adds browser-generated date and URL headers to the top and bottom of the page by default. These are not part of the memo format. If you must use it, uncheck "Headers and footers" in the print dialog. Chrome's built-in "Save as PDF" does not add these automatically.

Printing Other Tabs

Any tab can be printed using your browser's standard print command (Ctrl+P or Command+P). The navigation bar and buttons are hidden automatically. The active tab content is what prints.

Examples of when you might print other tabs:

  • Print the Planning tab to post at your desk as a reference for the period.
  • Print the Management View or Dashboard for a team meeting presentation.
  • Print Week 1 or Week 2 as a record of activity before the period closes.
Printed worklogs identify themselves When you print Week 1 or Week 2, a header is added at the top of the page showing your name, department, supervisor, and the pay period. That header is not visible on screen. It is filled in from the Name, Department, and Supervisor fields on the Memo tab, so fill those in before printing. If they are blank, the printed sheet will say "(name not entered)".

Print Note for Claude Desktop Users

If you are viewing the application inside the Claude Desktop HTML preview, the Print Memo button will not trigger a print dialog. This is a limitation of the sandboxed preview environment, not an error in the application. Open the AJSU-Tasker-v6.html file directly in Chrome or Edge for full print functionality.

11. Backups and Data Safety

How Data is Saved

The application saves your work automatically as you type using browser storage on your computer. As long as you do not clear your browser history or cookies, your work will be there the next time you open the application.

Clearing browser history deletes your data If you clear browser history, cookies, or site data, your work log data will be permanently removed from that browser. Always download a backup file before clearing your browser, switching computers, or resetting your browser profile.

Knowing Your Work Is Saved

A small Saved indicator with a timestamp appears in the top navigation bar each time your work is written to the browser. It updates as you type. This confirms your data is stored in this browser. It is not the same as downloading a backup file.

If saving ever fails, that indicator turns red and reads NOT SAVED, and the banner at the bottom of the screen changes to a saving-failure message. If you see that, download a backup immediately and do not close the tab until you have.

Next to the Saved time is a running count of everything stored for the year, for example 134 activities · 18 days. It covers the whole year, not just the pay period on screen, so the number should only ever grow as you work. It updates at natural stopping points - when you finish a block, switch tabs, or change pay period - rather than on every keystroke. If that count ever drops unexpectedly, restore your most recent backup before entering anything further.

Downloading a Backup

A red banner appears at the bottom of the screen when you have changes that have not been saved to a file. Click Download Backup in the export toolbar to save a JSON file to your computer. You can dismiss the banner with the × button at its right edge if it covers content you need to read. It is only a reminder. It reappears the next time you make a change.

Backup files are named automatically by year and the date and time you saved them:

AJSU-Tasker_2026_Backup_2026-09-02_1430.json

The file name carries the year rather than a period number because a backup always contains your whole year, every pay period, not only the one on screen when you clicked. Keep backups in a folder by year; the timestamp makes the newest one obvious at a glance. Trends history is captured automatically each time you switch pay periods, not on backup download.

Exporting a CSV

Click Export CSV in the export toolbar to download a spreadsheet of every activity you have logged, one row per activity, across all pay periods. It opens directly in Excel.

A CSV is a report, not a backup The CSV is for reading, sorting, and sharing your activity outside the application. It cannot be restored back into the Tasker. Only the JSON backup file can be restored, so keep downloading those as well.

Restoring a Backup

  1. Click Restore Backup in the top navigation bar.
  2. Select the backup JSON file from your computer.
  3. All data from that backup, including all blocks, planning notes, and trend history, is restored.
Restoring replaces current data Restoring a backup replaces everything currently in the application with the contents of that backup file. If you have unsaved current-session work, download a backup of it first.

Single User Only

This application saves data to a specific computer and browser profile. Do not share your browser profile with other users. Each person should have their own copy of the HTML file.

13. Frequently Asked Questions

Does my data stay when I close the browser?

Yes. The application saves automatically as you type. Your data will be there the next time you open the file in the same browser on the same computer.

What happens when I switch pay periods?

Your current period's data is saved. The application loads the entries and planning notes for the selected period. Switching back restores all your work for the original period. Switching periods also records your metrics in the Trends history.

What is the difference between "blocks" and "On Hold"?

Blocks (or activity blocks) are the individual rows you fill in on Week 1 and Week 2 - each row represents one unit of work. On Hold is a Status option for a block that has been stopped by an external obstacle, such as waiting for information from another party. These terms are kept distinct to avoid confusion.

Can I change the worksite after selecting one?

Yes. The worksite field is a standard dropdown. Click it and select a different location at any time. To clear it, select the blank option at the top of the list.

Do I need to do anything to build my Trends charts?

No. Trend data is recorded each time you switch pay periods. After working in two or more periods, the charts appear automatically. No backup download is needed to build trend history.

Why is the Worksite Distribution chart missing from the Trends tab?

The chart only appears if worksite data has been recorded in at least one period. If the Worksite field has not been used, the chart stays hidden. Start filling in worksite and it will appear after you switch to your next period.

What does it mean when the Trends tab says I only have 1 period?

Trend charts require data from at least 2 pay periods for comparison. Work in one more period (and switch away from it at least once) and the charts will appear.

My name and department are blank on the memo. Is that normal?

Yes. These fields are blank by default so the application works for any user without hardcoded names. Click on the Name or Department field on the Memo tab and type your information. The values are saved and will appear on every future session.

Can I edit the Pay Period dates on the memo?

Yes. Click on the date range next to "PAY PERIOD:" on the Memo tab to edit it before printing. The field resets to the computed date range when you switch pay periods.

The Print Memo button does not open a print dialog. What's wrong?

If you are viewing the application inside the Claude Desktop HTML preview, the print function is blocked by the preview environment's security settings. This is not an error in the application. Open AJSU-Tasker-v6.html directly in Chrome or Edge for full print functionality.

I cleared my browser history and lost my data. Can I recover it?

Only if you have a previously downloaded backup file. Click Restore Backup and select your most recent JSON backup. All data from that file will be restored. This is why downloading backups regularly is important.

Can two people use the same file on the same computer?

No. The application is single-user. Each person should have their own copy of the HTML file and use a separate browser profile. Sharing a browser profile will mix both users' data.

Does worksite information appear on the printed memo?

No. Worksite is a personal productivity metric visible in the Employee View and Dashboard. It is intentionally excluded from the Tasker Memo and the Management View.
