User Guide

How to Use

  • Pay Periods: Select the pay period from the menu bar dropdown. All dates for the chosen pay period update automatically.
  • Planning Tab: Planning notes are saved separately for each pay period. Feedback entered here appears in the Supervisor Notes section of the Tasker Memo.
  • Week 1 and Week 2 Tabs: Log your daily activity blocks here. Select a Category, type your Activity, choose a Status and Priority, select a Worksite, and add Notes. Status fields change background color automatically.
  • Block Categories: Leave/PTO, Meeting, Non-Recurring, Project, Routine.
  • Status Options: Complete, Delegated, Follow-up, In-Progress, On Hold, Pending, Re-assigned. Only On Hold, Follow-up, Delegated, and Re-assigned appear in the Management View.
  • Employee View Tab: Shows your completion rate, where your time went by category, priority load, and worksite breakdown for the current period.
  • Management View Tab: Shows items requiring supervisor attention, high-priority completions, and a full status count for the period.
  • Dashboard Tab: Visual charts for the current period — status breakdown, category mix, and worksite distribution. Charts only appear after activity is logged.
  • Trends Tab: Cross-period charts showing patterns across pay periods — not linear progress, but how your work mix, completion rate, and attention items shift over time. Switch pay periods to build history. Requires at least two periods of data.
  • Printing: Click the Print Memo button in the menu bar to print the Tasker Memo. For PDF output, select Save as PDF as the destination, uncheck Headers and Footers, check Print Backgrounds, then click Print.

System Requirements & Limitations

  • Single User Only: This application is personalized and saves to this specific computer and browser. Do not share your browser profile or log file with other users.
  • Do Not Clear Browser History: Clearing your browser history, cookies, or cache permanently deletes your saved records. Click Download Backup in the menu bar to save a backup. Print any tracker information before clearing your browser to prevent data loss.
  • The Tasker Log Carries Over Between Sessions: As long as you do not clear your browser history, your work restores automatically the next time you open this file.
  • The Backup File is Your Permanent Record: The red banner at the bottom appears when your work has not yet been exported to a backup file. Your entries are still saved automatically to this browser as you type — the banner is a reminder to also download a portable file copy, since clearing browser data would otherwise erase them permanently. Click Download Backup to save that copy, or dismiss the banner with the × button if it covers content you need to read — it will reappear on your next change.
  • The Saved indicator confirms your work is stored. The menu bar shows Saved with a timestamp each time your entries are written to this browser, updating as you type. If it turns red and reads NOT SAVED, download a backup immediately and do not close the tab until you have.
  • Backup files carry forward all saved data. Data in a backup file is permanent. To fix an incorrect task, restore the backup, correct the task directly in the app, then download a new backup to replace the old one.
  • Use Chrome or Edge for this file. Chrome and Edge reliably keep your saved data when you open this file directly. Firefox does not guarantee that data opened from a local file this way will still be there the next time you open it — this is a limitation of how Firefox handles locally-opened files, not something this app controls. Printing and file import also require Chrome or Edge; these features do not work inside preview panels or embedded viewers either.
